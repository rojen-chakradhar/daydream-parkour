## 🧩 About the Game  

**Daydream Parkour** is a short, adrenaline-filled parkour challenge where precision and timing decide everything.  
Built solo in under **6 hours**, it combines speed, simplicity, and clean level design to deliver a compact but intense experience.  

**Theme:** Parkour  
**Engine:** Godot 4.3  
**Duration:** 1-day hackathon  
**Team:** Just me 😎  

---

## ✨ Features  

- ⚡ Minimalist art style with smooth player movement  
- 🧱 Custom-built parkour levels  
- 🏁 Finish flag to complete the level  
- 💀 Death + restart system  
- 🎵 Simple, atmospheric background track  
- ⏱️ Lightweight and fast-paced gameplay
